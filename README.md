Techno-Genesis



A simple, responsive web application built using standard HTML and CSS.

📁 Repository Structure

├── index.html    # The main HTML entry file
└── style.css     # CSS stylesheet for application styling


🚀 Getting Started

No installation or build tools are required to run this project.

Running Locally

Clone the repository (or download the source code):

git clone https://github.com/2211akshmittal-del/Techno-Genesis.git


Navigate to the project directory:

cd your-repository-name


Open the project:

Double-click index.html to open it in your default browser, or

Right-click index.html and select Open With -> Google Chrome (or your preferred web browser).

HTML5 - Structure and Content

CSS3 - Styling and Design
